# Stepboard

Algebra 1 equation solver. Works one-, two-, and three-step equations line by line, with practice mode and word problems.

This is the first tool in **Algebra Workshop**.

## Run it on your computer

You need [Node.js](https://nodejs.org/) 22 or newer.

```bash
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:8080).

## What’s included

- Watch, Play, and Practice modes
- One-, two-, and three-step equations
- Word-problem mode
- Difficulty and coefficient controls

The classroom core is free to use.
