# Algebra Workshop

Classroom tools for Algebra 1, line by line.

- **Stepboard** (free) — one-, two-, and three-step equations, with practice mode and word problems
- **Inequalities** (Plus) — the same teaching board, with sign flip when multiplying or dividing by a negative, plus a number-line graph
- **Literal equations** (Plus) — solve a formula for one letter
- **Substitution** (Plus preview) — systems of two equations. Elimination is coming soon.

Live: https://algebraworkshop.com

## Run it on your computer

You need [Node.js](https://nodejs.org/) 22 or newer.

```bash
cd stepboard
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:8080).

The classroom core (Stepboard) is free to use. Inequalities, literal equations, and substitution are Plus boards; preview stays open until billing does. Elimination is coming soon.
